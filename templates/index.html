Sports Trivia and Games by Orion Hoch

Welcome

Hey, my name is Orion, I am a student at Cornell and I make sports trivia games in my free time. I like to store them here so random people can get a chance to play them! I hope to add a wide catalogue of a lot of fun stuff. A big thank you to all my friends at WVBR 93.5 for giving me the motivation to finally commit to storing some of these games. If it wasn't for them theres zero chance I would have had as much fun making these.

General Updates
Mar 2026
Multiplayer Lobby Update

The site now has a dedicated Multiplayer tab with room-based lobbies for Bullseye, Fantasy Duel, and Chain Game. You can create a lobby, claim Player 1-4 seats, and start once at least two players are in.

These online modes are polling-based for now, so they are meant for simple shared sessions and turn-based play rather than ultra-fast real-time action.

Mar 2026
Chain Multiplayer Added

Chain Game now has a multiplayer version where everyone gets the same live chain. Correct answers are banned globally for the rest of the game, and turns rotate through the seated players.

This mode keeps the same core chain logic, but moves state to the server so the whole room stays synced.

Mar 2026
Turn Lock Fixes

Online Fantasy Duel and Bullseye now use session-based player identity, which fixes the issue where two browser tabs could look like the same active player.

Play Again in multiplayer now returns everyone to the same lobby so the host can quickly run another match with the same group.

Next Up
What Is Still Experimental

The new multiplayer features are still in MVP form. Lobby flow, turn ownership, and shared state are in place, but the online modes will keep getting polish as more edge cases are tested.

For now, the safest way to test is with separate tabs or a normal window plus incognito so each player gets a unique session token.
